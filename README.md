1. **프로젝트 이해**: [프로젝트 목표](프로젝트%20목표.md) 먼저 읽기
2. **게임 설계**: [핵심 컨텐츠](시스템/핵심%20컨텐츠.md) → [게임 개요](시스템/게임%20개요.md)
3. **핵심 시스템**:
   - 스테이지 클리어: [스테이지 시스템](시스템/스테이지%20시스템.md) → [적 시스템](시스템/적%20시스템.md) → [전투 메카닉](시스템/전투%20메카닉.md)
   - 캐릭터 수집: [영웅 시스템](시스템/영웅%20시스템.md) → [획득/육성 시스템](시스템/영웅/획득%20시스템.md)
   - 영지 시스템: [영지 시스템](시스템/영지%20시스템.md) → [생산 시스템](시스템/영지/생산%20시스템.md)
4. **데이터 구조**: [데이터 테이블](시스템/데이터%20테이블.md) → 각 시스템 상세 문서
5. **세계관 확인**: [세계관 기획서](세계관%20기획서.md)
