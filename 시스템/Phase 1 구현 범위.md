# Phase 1 구현 범위

[← README로 돌아가기](../README.md)

> 본 문서는 Phase 1 프로토타입의 **포함 / 제외 / 임시 처리 / 성공 기준**을 정의하는 기준 문서다. 기존 [개발 로드맵](개발%20로드맵.md)의 Phase 1 서술과 충돌 시 본 문서를 우선한다.

---

## 1. Phase 1 목표

- **재미 검증용 전투 프로토타입** 완성.
- 공방형 라인 디펜스 + 부대 카드 운영이 실제로 재미있는지 빠르게 확인한다.
- 수익화, 소셜, 복잡한 영지 운영, 장기 수집 루프는 **최소화**한다.
- 이 단계의 성공 여부에 따라 Phase 2 이후의 확장 / 피봇 / 폐기를 결정한다.

## 2. 포함 범위

### 2.1 컨텐츠 분량

| 항목 | Phase 1 수량 |
|------|-------------|
| 영웅 | 5명 |
| 소환 유닛 | 5종 |
| 적 | 5종 |
| 보스 | 1종 |
| 챕터 | 1챕터 |
| 스테이지 | 5스테이지 |

### 2.2 전투 코어 기능

- **공방형 라인 디펜스 구조** ([전투 코어](전투%20코어.md))
  - 적/아군 본진 양측 존재
  - 본진 파괴 시 승/패 처리
- **라인 구조**: 지상 2라인 + 공중 1라인
- **마나 시스템**
  - 마나 회복 (초당 자동)
  - 마나 소모 (소환 유닛 출격)
- **소환 유닛 출격**
  - 슬롯 메인 버튼 → 라인 선택 → 출격
  - 슬롯 쿨다운 적용
- **영웅 직접 출격** ([부대 카드 시스템](부대%20카드%20시스템.md))
  - 슬롯 비활성화
  - 수동 귀환 / 전투불능 처리 (임시 수치)
- **기본 승패 처리**
  - 적 본진 파괴 → 승리
  - 아군 본진 파괴 → 패배
- **간단 보상**
  - 클리어 보상 1회 지급 (별 평가, 재화 일부)
  - 복잡한 일일/주간/이벤트 보상은 제외

## 3. 제외 / 보류 범위

다음 항목은 Phase 1에서 **구현하지 않는다.** 일부는 더미/플레이스홀더로 대체 가능하지만, 실제 시스템 구현은 보류한다.

| 카테고리 | 제외 항목 |
|----------|-----------|
| 수익화 | 10연차 가챠, 과금 결제, 방문 영웅 영입 결제, 상점 |
| 소셜 | PvP, 길드, 친구, 채팅 |
| 라이브 운영 | 이벤트, 이벤트 스테이지, 시즌 패스 |
| 장비 | 복잡한 장비 세트 효과, 장비 강화 실패, 옵션 재롤 |
| 전투 깊이 | 속성 상성, 종족 상성 |
| 영웅 획득 | 제조 + 방문 영웅 + 가챠 병행 여부 (정책 미결정, 본 문서 §6 참조) |
| 아트 | Live2D, 일러스트 컷씬, 본격 픽셀아트 |
| 결제 | 과금 결제 SDK 연동 |

### 3.1 영입/수익화 정책 (보류)

- **제조 + 방문 영웅 + 가챠 병행 여부**는 Phase 1 단계에서 결정하지 않는다.
- Phase 1은 영웅을 **수동 부여(테스트 계정에 지급)** 방식으로 진행한다.
- 영입/수익화 정책 결정 이후 Phase 2~3에 반영한다.

## 4. 임시 처리

| 항목 | 처리 방식 |
|------|-----------|
| 아트 | **플레이스홀더** (도형/단색 스프라이트 또는 무료 에셋) |
| 서버 | **로컬 / 더미 데이터 가능** (서버 없이 클라이언트 단독 진행 허용) |
| 밸런스 수치 | **임시값** (마나 회복량, 본진 HP, 유닛/영웅 스탯 모두 추후 재조정 전제) |
| 사운드 | 무음 또는 무료 에셋 |
| 로컬라이제이션 | 한국어 단일 |

## 5. 성공 기준

Phase 1은 다음 기준을 통과해야 "재미 검증 통과"로 간주한다.

1. **전투 1판이 2~4분 내에 끝난다.**
   - 너무 짧거나 너무 길지 않음.
2. **플레이어가 "유닛 소환"과 "영웅 직접 출격" 사이에서 의미 있는 선택을 느낀다.**
   - 영웅 출격이 단순 정답이 아니라 트레이드오프로 느껴짐.
3. **라인 하나가 밀리거나 뚫리는 상황이 눈에 보인다.**
   - 라인별 압박을 시각적으로 인지 가능.
4. **5스테이지에서 최소 한 번은 다른 전술이 요구된다.**
   - 같은 덱/같은 운영으로 5스테이지를 다 못 깸. 적어도 1회는 전술 변화를 요구.

> 위 기준이 충족되지 않으면 부대 카드 / 라인 / 마나 시스템 중 어느 축을 손볼지 별도 판단한다.

## 6. 기존 로드맵과의 정렬

- [개발 로드맵 - Phase 1](개발%20로드맵.md#phase-1-프로토타입)의 Phase 1 항목은 본 문서와 다음과 같이 정렬된다.

| 기존 로드맵 항목 | 본 문서 처리 |
|------------------|--------------|
| 기본 전투 시스템 | 공방형 라인 디펜스로 재정의됨 (§2.2) |
| 덱 편성 | 부대 카드 5슬롯 (영웅+소환 유닛 묶음) |
| 링크 시스템 (1-3링크) | **Phase 1 보류** (단순화, 필요 시 최소 더미만) |
| 플레이스홀더 아트 | 유지 (§4) |
| 영웅 5 / 소환 유닛 5 / 적 5 / 보스 1 / 1챕터 5스테이지 | 유지 (§2.1) |

- 본 문서가 더 좁은 범위를 정의한다. 기존 로드맵의 "링크 시스템 (1-3링크)" 등 일부 항목은 Phase 1 보류로 본다.
