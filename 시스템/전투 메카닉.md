## 데미지 계산 공식

> 모든 엔티티 간 피해 계산에 동일 적용 (평타, 스킬 공통)

### 통합 공식

**Phase 1 (초기 버전)**
```
최종 피해 = 피해량 × (100 / (100 + 방어력)) × 치명타 배율
```

**Phase 2 (속성 추가 시)**
```
최종 피해 = 피해량 × (100 / (100 + 방어력)) × 치명타 배율 × 속성 배율
```

### 1단계: 피해량 계산

| 공격 유형 | 물리 피해량     | 마법 피해량     |
| ----- | ---------- | ---------- |
| 평타    | ATK        | MAG        |
| 스킬    | 각 스킬 마다 다름 | 각 스킬 마다 다름 |

#### 스킬 계수 예시

| 스킬   | 피해량 공식         | 설명        |
| ---- | -------------- | --------- |
| 강타   | ATK × 1.5      | 순수 계수형    |
| 파이어볼 | 50 + MAG × 2.0 | 기본값 + 계수형 |
| 연속베기 | ATK × 0.8 × 3회 | 다단히트      |
| 관통사격 | ATK × 1.2 (관통) | 특수 효과 포함  |

### 2단계: 방어력 적용

| 피해 타입 | 적용 방어력 | 계산식                       |
| ----- | ------ | ------------------------- |
| 물리    | DEF    | 피해량 × (1 - DEF/(DEF+100)) |
| 마법    | RES    | 피해량 × (1 - RES/(RES+100)) |

**개선 사유:**
- 이전 공식의 무한 스택 문제 해결
- 직관적 계산: 감소율 = DEF / (DEF + 100)
- 에르엘워즈 벤치마킹

#### 방어력 효율

| DEF/RES | 피해 감소율 |
| ------- | ------ |
| 0       | 0%     |
| 50      | 33%    |
| 100     | 50%    |
| 200     | 67%    |
| 300     | 75%    |

**특징:**
- 방어 스탯은 수확체감 구조 (무한 스택 방지)
- DEF가 높을수록 효율이 떨어지지만 항상 의미 있음
- 최대값: 무한 DEF = 100% 감소 (이론적)

### 3단계: 추가 배율

| 배율 종류 | 조건 | 배율 | 적용 시기 |
|-----------|------|------|-----------|
| 치명타 | CRT 확률로 발동 | ×1.5 | Phase 1 |
| 속성 강점 | 상성 우위 | ×1.5 | Phase 2 |
| 속성 약점 | 상성 열위 | ×0.75 | Phase 2 |

### 계산 예시

#### 예시 1: 평타 (물리)
```
ATK 100, 대상 DEF 50, 치명타 미발동
피해량 = 100
방어 적용 = 100 × (100 / 150) = 66.7
최종 피해 = 66.7
```

#### 예시 2: 스킬 (마법, 속성 우위)
```
파이어볼: 50 + MAG × 2.0
MAG 80, 대상 RES 30, 화염 속성, 대상 자연 속성 (약점)
피해량 = 50 + (80 × 2.0) = 210
방어 적용 = 210 × (100 / 130) = 161.5
속성 배율 = 161.5 × 1.5 = 242.3
최종 피해 = 242.3
```

## 넉백(Knockback) 시스템

### 무게(Weight) 스탯

모든 유닛에 무게 스탯 추가:

```
무게 = (HP + DEF × 2) / 10 [반올림]

범위: 5 ~ 150

예시:
- 고블린: (150 + 10×2) / 10 = 17
- 기사(탱커): (500 + 40×2) / 10 = 58
- 늑대(경장): (100 + 8×2) / 10 = 12
- 골렘(초중량): (800 + 60×2) / 10 = 92
```

**특징:**
- HP와 DEF 모두에 영향 (탱커가 무겁고 경장이 가벼움)
- 넉백 저항력 결정

### 넉백 거리 계산

```
넉백 거리 = (공격력 × 1.5) / (대상 무게 × 0.8)
제약: 최소 0, 최대 3칸

기병 유닛(Cavalry): 공격력에 2.5배 가중치 추가
공중 유닛: X축 넉백 + Y축 5% 상승
```

**예시:**
```
근력사(ATK 80) → 일반 고블린(무게 17)
= (80 × 1.5) / (17 × 0.8) = 8.8칸 → 최대 3칸으로 제한

기사(ATK 50, DEF 40) → 고블린 왕(무게 73)
= (50 × 1.5) / (73 × 0.8) = 1.3칸
```

### 넉백 스킬 속성

스킬에 다음 속성 추가:

```json
{
  "skill": {
    "name": "강타",
    "knockback_power": 1.5,
    // 0 = 넉백 없음
    // 0.5 ~ 1.5 = 일반 스킬
    // 2.0 = 강력한 넉백 (기병 전용)

    "knockback_direction": "forward"
    // 'forward' = 뒤로 밀림
    // 'backward' = 앞으로 끌어옴
    // 'upward' = 위로 띄움 (공중 유닛용)
  }
}
```

### 넉백 효과

```
1. 거리 계산: 공격력과 무게를 이용해 넉백 거리 결정
2. 방향 적용: 넉백 방향에 따라 이동
3. 위치 변경: 새 위치로 순간 이동 (또는 부드러운 애니메이션)
4. 피해 없음: 넉백 자체는 추가 피해 없음, 다만 배치 이동이 주는 전술적 가치
```

## 속성 상성 (Phase 2)

> 초기 버전에서는 미적용, 후반 업데이트에서 추가 예정

| 속성 | 강함 (1.5배) | 약함 (0.75배) |
|------|--------------|---------------|
| 화염 | 자연/빙결 | 수속성 |
| 빙결 | 수속성 | 화염 |
| 번개 | 수속성/기계 | 대지 |
| 대지 | 번개 | 자연 |
| 자연 | 대지 | 화염 |
| 암흑 | 신성 | 신성 |
| 신성 | 암흑 | 암흑 |

### 상태이상

**디버프**: 화상, 빙결, 감전, 중독, 출혈, 스턴

**버프**: 공격 강화, 방어 강화, 신속, 재생, 보호막
