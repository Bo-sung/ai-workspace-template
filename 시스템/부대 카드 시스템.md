# 부대 카드 시스템

[← README로 돌아가기](../README.md)

> 본 문서는 영웅+소환 유닛을 묶은 **부대 카드(덱 슬롯)** 운영 규칙을 정의하는 기준 문서다. 전투의 큰 흐름은 [전투 코어](전투%20코어.md)를 따른다.

---

## 1. 핵심 정의

- **덱 슬롯 1개 = 영웅 1명 + 소환 유닛 1종**의 묶음.
- 이 묶음을 "부대 카드"로 부른다.
- 덱은 5슬롯 기본 (기존 영웅 덱 슬롯 정의를 유지).
- 슬롯은 전투 중 두 가지 행동의 기점이 된다.
  1. 소환 유닛 출격 (평상시)
  2. 영웅 직접 출격 (결단)

---

## 2. 평상시 행동: 소환 유닛 출격

- 슬롯의 메인 버튼을 누르면 해당 슬롯에 묶인 **소환 유닛**이 지정 라인에 출격한다.
- 소환 유닛은 다음 비용을 가진다.

| 비용 항목 | 설명 |
|-----------|------|
| 마나 | 전투 자원 마나를 소모 (수치 임시값) |
| 슬롯 쿨다운 | 출격 후 짧은 슬롯 단위 쿨다운 발생, 동일 슬롯 연속 출격 제한 |

- 슬롯 쿨다운은 해당 슬롯에만 적용되며, 다른 슬롯에는 영향 없음.
- 동일 소환 유닛이 다른 슬롯(=다른 영웅)에 묶여 있으면 해당 슬롯의 쿨다운으로 별도 출격 가능 (공유 풀 아님).

---

## 3. 영웅 직접 출격

- 같은 슬롯에 묶인 **영웅 본인**이 전장에 직접 출격할 수 있다.
- 영웅은 평상시에는 본진/후방에서 자동 공격을 하거나 전장 외부에 있다고 본다. (상세 표현은 UI/연출 결정 사항)
- 영웅 출격은 결단 행동이며, 무료 남발이 아닌 **전술적 카드 사용**으로 설계한다.

### 3.1 슬롯 비활성화 규칙

- 영웅이 전장에 출격해 있는 동안, **해당 슬롯은 비활성화** 상태가 된다.
- 슬롯 비활성화 효과:
  - 해당 소환 유닛 추가 소환 **불가**.
  - 이미 라인에 출격해 있는 같은 종류의 소환 유닛은 **유지**되고 정상 행동한다.
  - 다른 슬롯/다른 영웅의 행동에는 영향 없음.
- 즉 영웅 출격은 "이 슬롯은 영웅이 직접 손을 쓰러 갔다"는 상태이며, 동일 부대의 추가 보급이 잠시 끊기는 트레이드를 강제한다.

### 3.2 귀환 / 전투불능 처리

| 상황 | 결과 |
|------|------|
| **수동 귀환** | 짧은 복귀 쿨다운 후 슬롯 재활성화. 영웅은 후방으로 돌아오고 소환 출격 다시 가능. |
| **전투불능 (사망/탈락)** | 긴 복귀 쿨다운 후 슬롯 재활성화. 또는 해당 전투 동안 재출격 불가 처리 (Phase 1에서 결정). |

- 정확한 쿨다운 수치, 복귀 시 HP 비율, "전투불능 후 재출격 가능 여부"는 **Phase 1에서 임시값으로 진행**한다.
- 임시 기준 (조정 가능):
  - 수동 귀환 쿨다운: 약 7초
  - 전투불능 쿨다운: 약 20초 또는 전투 동안 재출격 불가

---

## 4. 영웅과 소환 유닛의 관계

- **소환 유닛은 여러 영웅이 공유할 수 있다.** (예: 궁병은 궁수 영웅 A와 궁수 영웅 B의 슬롯 양쪽에 묶일 수 있음.)
- 다만 같은 소환 유닛이라도 **묶인 영웅에 따라 보정이 다를 수 있다.**
  - 예: 기사 영웅에게 묶인 중갑병은 방어력 보정, 다른 탱커 영웅에게 묶인 중갑병은 체력 보정.
- 영웅과 소환 유닛의 매칭은 기본적으로 **콘텐츠 사이드의 고정 매칭**으로 시작한다.
  - 추후 "교체 가능 병종 슬롯" 여부는 [보류 / 결정 필요](#7-보류--결정-필요) 참조.

### 4.1 예시 표 (Phase 1 후보)

| 영웅 역할 예시 | 묶인 소환 유닛 예시 |
|----------------|---------------------|
| 기사 영웅 | 중갑병 |
| 궁수 영웅 | 궁병 |
| 마법사 영웅 | 마도병 |
| 기병 영웅 | 기병대 |
| 사제 영웅 | 수습 사제 |

> 위 매칭은 예시이며, 영웅 5명 / 소환 유닛 5종 구성의 후보안이다. 최종 명칭/스탯은 별도 데이터 테이블에서 정의한다.

## 5. UI 기본 방향

| 요소 | 동작 |
|------|------|
| **슬롯 메인 버튼** | 탭 → 해당 라인 선택 → 소환 유닛 출격 |
| **영웅 초상화 / 별도 버튼** | 탭 → 라인 선택 → 영웅 직접 출격 |
| **슬롯 비활성화 표시** | 영웅 출격 중 슬롯 메인 버튼은 dimmed 처리 + "영웅 출격 중" 라벨 |
| **귀환 버튼** | 영웅 출격 중 슬롯/영웅 아이콘 탭 시 노출, 수동 귀환 트리거 |
| **쿨다운 표시** | 슬롯 쿨다운(소환 직후) / 영웅 복귀 쿨다운 / 영웅 전투불능 쿨다운을 시각적으로 분리 |

- 슬롯과 영웅을 한 카드 안에서 명확히 분리해 보여줘야 한다. (이중 운용이 이 시스템의 핵심)
- 구체 레이아웃은 [UI 설계](UI%20설계.md)에서 후속 작업.

---

## 6. 기존 문서와의 차이 (참고)

- 기존 [영웅 시스템](영웅%20시스템.md)은 "영웅 = 마나 0 무료 배치 카드"로 서술되어 있다.
- 본 문서는 그 정의를 **부대 카드의 한 축으로 격상**하고, 무료 남발이 아닌 슬롯 비활성화라는 트레이드를 가진 결단 행동으로 재정의한다.
- 따라서 영웅 시스템의 "배치 시스템" 섹션은 후속 PR에서 본 문서로 흡수/연동 재서술 대상이다.

---

## 7. 보류 / 결정 필요

- **영웅 직접 출격의 마나 비용 여부**
  - 0으로 둘지, 일정 비용을 둘지, 영웅 등급/티어에 따라 가변으로 둘지.
- **영웅 전투불능 후 재출격 가능 여부**
  - 긴 쿨다운 후 재출격 허용 vs 해당 전투 재출격 불가.
- **소환 유닛 매칭 형태**
  - 영웅별 고정 매칭으로 둘지, 영웅에 "병종 슬롯"을 만들어 같은 카테고리 내에서 교체 가능하게 둘지.
- **링크 시스템 적용 범위**
  - 기존 [링크 시스템](영웅/링크%20시스템.md)을 영웅에만 적용할지, 소환 유닛에도 별도 링크/강화 개념을 둘지.
- **영웅 출격 중 슬롯 쿨다운 동작 방식**
  - 영웅 출격 중에는 슬롯 쿨다운을 일시 정지할지, 그대로 흘려보낼지.
