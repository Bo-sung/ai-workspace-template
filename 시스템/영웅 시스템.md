# 영웅 시스템

[← README로 돌아가기](../README.md)

> 본 문서는 **공방형 라인 디펜스 RPG** 기준에서 영웅의 정체성, 덱 편성, 전투 역할을 정의한다. 전투 정체성은 [전투 코어](전투%20코어.md), 슬롯 운영 상세는 [부대 카드 시스템](부대%20카드%20시스템.md), 스테이지 운용은 [스테이지 시스템](스테이지%20시스템.md)을 따른다.

---

## 1. 개요

- **영웅은 수집/육성 대상이자 부대 카드의 중심**이다.
- 영웅은 단독으로 전장에 던지는 카드가 아니라, 묶인 소환 유닛과 함께 운용되는 **부대 카드**의 핵심 구성요소다.
- 전투 중 슬롯/출격/귀환 등 세부 규칙은 [부대 카드 시스템](부대%20카드%20시스템.md)을 참조한다. 본 문서는 영웅 자체의 정의, 역할, 등급, 육성 관련 하위 시스템 진입점만 다룬다.

---

## 2. 출격 덱과 부대 카드

### 2.1 덱 구조

- **출격 덱 = 부대 카드 5슬롯** (Phase 1 기준).
- 슬롯 1개 = **영웅 1명 + 소환 유닛 1종** 묶음.
- 덱에 넣은 **부대 카드**만 전투에서 소환 출격 / 영웅 직접 출격에 사용할 수 있다.
- 역할 제한 없음. 탱커 5슬롯, 원거리 5슬롯 등 자유 구성 가능 (전술적 불이익은 별개).

### 2.2 Phase 1 범위

- 영웅 5명 / 소환 유닛 5종 ([Phase 1 구현 범위](Phase%201%20구현%20범위.md) 기준).
- 영웅 매칭 예시는 [§5 영웅과 소환 유닛의 관계](#5-영웅과-소환-유닛의-관계) 참조.

---

## 3. 영웅의 전투 역할

영웅은 전투에서 네 가지 방식으로 기여한다.

| 기여 방식 | 설명 |
|-----------|------|
| **소환 유닛 보정** | 슬롯에 묶인 영웅 특성에 따라 동일 소환 유닛도 다르게 강화될 수 있다. (예: 기사 영웅 휘하 중갑병 = 방어 보정) |
| **직접 출격** | 결단 행동으로 영웅이 라인에 직접 투입된다 ([§4](#4-영웅-직접-출격)). |
| **스킬/패시브 제공** | 영웅 고유 스킬은 직접 출격 시 발현되며, 일부는 부대 단위 패시브로 작용할 수 있다 (상세는 [스킬 시스템](스킬%20시스템.md)). |
| **덱 빌딩 정체성** | 어떤 영웅을 데려오느냐가 그 슬롯의 부대 색깔을 결정한다. |

---

## 4. 영웅 직접 출격

> 본 절은 요약이다. 상세 규칙은 [부대 카드 시스템 §3](부대%20카드%20시스템.md#3-영웅-직접-출격)을 따른다.

### 4.1 기본 규칙

- 영웅 초상화 / 별도 버튼 탭 → 라인 선택 → **영웅이 라인에 직접 출격**.
- **슬롯 비활성화**: 영웅이 출격해 있는 동안 해당 슬롯은 비활성화된다.
  - 해당 슬롯의 **소환 유닛 추가 출격 불가**.
  - **이미 라인에 출격해 있는 같은 소환 유닛은 유지**되고 정상 행동한다.
  - 다른 슬롯/다른 영웅 행동에는 영향 없음.

### 4.2 귀환 / 전투불능

| 상황 | 처리 |
|------|------|
| **수동 귀환** | 짧은 복귀 쿨다운 후 슬롯 재활성화 (임시값: 약 7초) |
| **전투불능** | 긴 복귀 쿨다운 후 슬롯 재활성화, 또는 해당 전투 재출격 불가 (임시값: 약 20초) |

- 수치는 **임시값**이며 Phase 1에서 조정 대상이다.
- 재출격 가능 여부 자체는 [§10 결정 필요](#10-결정-필요).

### 4.3 비용

- 영웅 직접 출격에 마나 비용을 둘지는 **결정 보류** ([§10](#10-결정-필요)).
- "영웅을 마나 0으로 언제든 무료 배치한다"는 구버전 규칙은 본 문서의 확정 사양이 아니다.

---

## 5. 영웅과 소환 유닛의 관계

- **같은 소환 유닛을 여러 영웅이 공유할 수 있다.**
  - 예: 궁병은 궁수 영웅 A의 슬롯에도, 다른 궁수 계열 영웅 B의 슬롯에도 묶일 수 있다.
- **같은 소환 유닛이라도 묶인 영웅에 따라 보정이 다르다.**
  - 영웅이 가진 역할/스탯/특성에 따라 동일 병종의 강조점이 달라진다.
- 매칭 형태(영웅 고정 매칭 vs 병종 카테고리 슬롯 교체)는 [§10 결정 필요](#10-결정-필요).

### 5.1 Phase 1 매칭 후보 예시

| 영웅 역할 예시 | 묶인 소환 유닛 예시 |
|----------------|---------------------|
| 기사 영웅 | 중갑병 |
| 궁수 영웅 | 궁병 |
| 마법사 영웅 | 마도병 |
| 기병 영웅 | 기병대 |
| 사제 영웅 | 수습 사제 |

> 예시이며 최종 명칭/스탯은 별도 데이터 작업에서 정의한다.

---

## 6. 역할 분류

영웅은 스탯 특성에 따라 자연스럽게 역할이 갈린다. 본 분류는 **시스템 강제가 아니라 운용 가이드**다.

| 역할 | 스탯 특성 | 부대 카드 효과 방향 (예시) |
|------|-----------|---------------------------|
| **탱커** | 높은 HP/DEF | 직접 출격 시 라인 흡수 + 묶인 소환 유닛 방어 보정 |
| **근접 딜러** | 높은 ATK, 짧은 RNG | 직접 출격 시 본진 압박 + 소환 유닛 공격 보정 |
| **원거리 딜러** | 높은 ATK, 긴 RNG | 직접 출격 시 후방 견제 + 소환 유닛 사거리/명중 보정 |
| **마법사** | 높은 MAG, 긴 RNG | 직접 출격 시 광역 처리 + 소환 유닛 마법 보정 |
| **지원** | 힐/버프 스킬 | 직접 출격 시 아군 부대 유지 + 소환 유닛 생존 보정 |

### 6.1 재정의 포인트

- 본 문서에서 역할은 **직접 출격 성능**과 **소환 유닛 보정** 두 축 모두에 영향을 준다.
- 시스템 차원의 조합 보너스(예: 탱커 2명 필수)는 두지 않는다.

---

## 7. 등급 시스템

### 7.1 별 등급 (기존 구조 유지)

- 1성 ~ 5성.
- **모든 영웅 5성까지 승급 가능.**
- 초기 등급은 획득 난이도와 초반 성능에 영향을 준다. 최종 성능은 동일 레벨/승급 기준으로 수렴한다.

### 7.2 등급의 적용 범위 (재검토)

- 등급 상승이 **소환 유닛 보정 강도** / **직접 출격 성능** / **스킬 해금** 각각에 어떻게 반영되는지는 **확정되지 않았다.**
- Phase 1 임시안: 직접 출격 성능 강화에 집중, 소환 유닛 보정/스킬 해금 정책은 후속 결정.
- 자세한 승급 수치 테이블은 [데이터 테이블 - 영웅](데이터%20테이블.md#영웅-테이블) 참고.

---

## 8. 링크 시스템과의 관계

> 상세 규칙은 [링크 시스템](영웅/링크%20시스템.md). 본 절은 새로운 부대 카드 구조 위에서의 적용 범위만 정리한다.

### 8.1 현 상태

- 기존 링크 시스템은 영웅 1명 + 병사 N명을 묶어 "부대 HP / 부대 화력"으로 다룬다.
- 본 문서의 부대 카드 구조에서는 **소환 유닛이 별도 자원으로 라인에 출격**하므로, 링크가 누구에게 적용되는지를 다시 정의해야 한다.

### 8.2 Phase 1 권장안 (확정 아님)

- 링크는 우선 **영웅 직접 출격 성능**에 적용한다.
- 소환 유닛에 대한 링크/강화 개념 적용은 **Phase 2 검토**.
- 위 권장안은 결정이 아니며 [§10 결정 필요](#10-결정-필요)에 따라 변경될 수 있다.

## 10. 결정 필요

- 영웅 직접 출격 마나 비용 여부
- 영웅 전투불능 후 재출격 가능 여부 (긴 쿨다운 vs 해당 전투 재출격 불가)
- 소환 유닛 매칭: 영웅별 고정 매칭 vs 영웅이 카테고리 슬롯을 가지고 병종 교체 허용
- 링크 시스템 적용 범위: 영웅 직접 출격에만 한정 vs 소환 유닛에도 별도 링크/강화 개념 도입
- 영웅 출격 중 해당 슬롯의 쿨다운 일시 정지 여부
- 영웅 출격 중 본진 자동 공격 / 부속 시설의 영향 여부 (구 "타워 무기 비활성화" 처리)
- 직접 출격한 영웅의 라인 간 이동 허용 여부
- 등급 상승의 적용 축 (직접 출격 성능 / 소환 유닛 보정 / 스킬 해금 각각의 비중)

## 11. 구버전에서 대체된 표현

본 문서는 다음 구버전 표현을 더 이상 **확정 규칙**으로 두지 않는다. 일부는 격리/결정 필요로 이동, 일부는 부대 카드 시스템으로 흡수되었다.

| 구버전 | 처리 |
|--------|------|
| 출격 덱 = 영웅 보관함 | 출격 덱 = 부대 카드 5슬롯 (영웅 + 소환 유닛)으로 재정의 (§2) |
| 덱에 넣은 영웅만 전투에서 배치 가능 | 덱에 넣은 부대 카드만 소환/영웅 출격 가능 (§2) |
| 영웅 배치 비용 마나 0 / 인구수 0 (확정) | 부대 카드 시스템으로 흡수, 비용은 결정 보류 (§4.3) |
| 영웅은 기본 상태에서 성벽 위 원거리 공격 | 본진 자동 공격/부속 시설 결정 필요로 격리, 기본 상태는 후방/덱 슬롯 (§4, §10) |
| 영웅 배치 시 해당 라인 타워 무기 비활성화 | 본진 자동 공격 자체가 결정 필요이며, 영향 여부도 결정 필요 (§10) |
| 회수 7초 / 부활 20초 (확정 규칙) | 임시값 예시 (§4.2) |
| 영웅 회수/재배치 반복으로 DPS 운용 | 직접 출격은 슬롯 비활성화 트레이드를 동반하는 결단 행동 (§4, [부대 카드 시스템](부대%20카드%20시스템.md)) |
