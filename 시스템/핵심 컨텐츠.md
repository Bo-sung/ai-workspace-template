# 핵심 컨텐츠

[← README로 돌아가기](../README.md)

> 본 문서는 게임의 **3대 핵심 컨텐츠 축**과 그 연결 구조를 정의한다. 전투 정체성/슬롯 운영/Phase 1 범위의 세부는 [전투 코어](전투%20코어.md), [부대 카드 시스템](부대%20카드%20시스템.md), [Phase 1 구현 범위](Phase%201%20구현%20범위.md)를 따른다.

---

## 1. 개요

게임 플레이는 다음 **3대 핵심 컨텐츠**를 축으로 한다.

- **영지 시스템** — 메타 성장과 자원 생산 (내실)
- **스테이지 공방전** — 실제 플레이와 성장 검증 (중심)
- **캐릭터와 부대 카드 수집** — 유입, 장기 목표, 덱 빌딩 (유입)

3대 축은 그대로 유지하되, **전투 중심축은 공방형 라인 디펜스 + 부대 카드 운용**으로 재정의된다. 단순 방어형 타워디펜스 / 영웅 무료 배치 기반의 구버전 서술은 본 문서에 더 이상 적용되지 않는다.

---

## 2. 핵심 컨텐츠 요약

| 축 | 정의 | 역할 |
|----|------|------|
| **영지 시스템** | 영지를 건설/업그레이드해 자원을 생산하고 메타 성장을 누적 | 내실 (성장 기반, 일일 접속 동기) |
| **스테이지 공방전** | 부대 카드를 라인에 운용해 적 본진을 파괴하고 아군 본진을 지키는 공방형 라인 디펜스 | 중심 (실제 플레이, 성장 활용처) |
| **캐릭터와 부대 카드 수집** | 영웅 수집 + 소환 유닛 매칭 + 영웅별 보정 + 링크/육성/장비 | 유입 (장기 목표, 덱 빌딩) |

## 3. 영지 시스템 (Manor System)

### 3.1 정의

플레이어가 소유한 영지를 건설/업그레이드하고 자원을 생산해 게임 진행의 기반을 마련하는 메타 시스템.

### 3.2 핵심 요소

- **건물 건설 & 업그레이드**: 대장간, 훈련소, 수리실, 생산 건물 등.
- **자원 생산**: 영지 시설에서 자동으로 생산되는 자원 (은화, 식량, 마석, 보급, 인력).
- **전투/육성과의 연결**: 영지 자원이 다음으로 흐른다.
  - **소환 유닛 출격 자원** (마나 강화 등 [스테이지 시스템 §4](스테이지%20시스템.md#4-마나-시스템) 참고)
  - **영웅 육성 / 승급 / 장비 강화** ([영웅 시스템](영웅%20시스템.md))
  - **전투 후 수리** ([수리 시스템](영웅/수리%20시스템.md))
- **수익화 포인트**: 건설 시간 가속, 슬롯 확장 등. 단 **Phase 1에서는 최소화** ([Phase 1 구현 범위](Phase%201%20구현%20범위.md) 기준).

### 3.3 플레이 흐름

```
건물 건설 → 자원 생산 → 자원 소비 (마나/육성/수리) → 더 강한 부대 카드 운용 가능
```

### 3.4 역할

- **내실**: 게임 전체의 메타 기반.
- **성장 가시화**: 자원 생산 → 건물 업그레이드 → 자원 생산 강화의 선순환.
- **일일 접속 유도**: 매일 자원 수확과 건설 완료 체크.
- **진행 속도 조절**: 가속 결제로 수익화 / 만족도 양립 (수익화 정책 결정 후 적용).

### 3.5 관련 문서

- [영지 시스템](영지%20시스템.md)
- [영지/생산 시스템](영지/생산%20시스템.md)
- [영지/데이터 명세](영지/데이터%20명세.md)

## 4. 스테이지 공방전 (Stage Combat)

### 4.1 정의

부대 카드(영웅 + 소환 유닛)를 라인에 운용해 **적 본진을 파괴하고 아군 본진을 지키는** 공방형 라인 디펜스 RPG의 핵심 컨텐츠.

- "스테이지 클리어"는 본 문서 기준에서 **공방형 스테이지의 클리어**를 의미한다. 단순 웨이브 전멸이 아니다.
- 일방향 방어 컨텐츠는 [스테이지 시스템 §10](스테이지%20시스템.md#10-방어-전용-모드)의 방어 전용 모드로 격리한다.

### 4.2 핵심 요소

- **본진 HP**: 양측이 본진 HP를 보유. 한쪽 본진 HP 0 도달 시 즉시 승/패.
- **라인 구조**: 지상 2라인 + 공중 1라인 (Phase 1 기본).
- **마나 기반 소환 유닛 출격**: 슬롯 메인 버튼으로 라인 선택 후 출격, 마나 소모.
- **영웅 직접 출격**: 결단 행동. 출격 중 해당 슬롯 비활성화 (추가 소환 불가, 기출격 유닛은 유지).
- **적 출격 패턴 / 보스**: 구 "웨이브" 개념을 적 본진의 출격 패턴으로 재정의.
- **보상 / 평가**: 본진 HP 유지, 클리어 시간, 영웅 전투불능 여부 기준으로 별 평가 (수치 임시값).

### 4.3 플레이 흐름

```
덱 편성 (부대 카드 5슬롯) →
스테이지 진입 →
라인 / 초기 마나 / 본진 위치 확인 →
전투 시작 (마나 회복 시작) →
소환 유닛 출격 (슬롯 메인 버튼, 마나 소모) →
영웅 직접 출격 판단 (슬롯 비활성화 트레이드) →
라인 공방 →
적 본진 파괴 (승리) / 아군 본진 방어 실패 (패배) →
결과 / 보상 / 수리
```

### 4.4 역할

- **성장 활용처**: 영웅 육성/링크/장비/소환 유닛 매칭이 실제 효과로 나타나는 공간.
- **주력 컨텐츠**: 플레이 시간 대부분을 차지.
- **전술적 재미**: 어느 라인에 누구를 출격시키고, 언제 영웅을 직접 투입할지가 선택의 핵심.
- **보상 루프**: 클리어 → 보상 → 영지/육성 → 더 어려운 공방전 도전.

## 5. 캐릭터와 부대 카드 수집 (Card Collection)

### 5.1 정의

영웅을 영입하고 육성할 뿐 아니라, **어떤 소환 유닛을 어떤 영웅 보정과 함께 운용할지**까지 포함하는 수집 / 덱 빌딩 컨텐츠.

- "캐릭터 수집"은 본 문서에서 **영웅 + 소환 유닛 + 부대 카드 운용 옵션**까지 포함하는 개념으로 확장된다.
- "영웅 뽑기 = 수집"이라는 좁은 의미는 본 기준에서 더 이상 충분하지 않다.

### 5.2 핵심 요소

#### 영웅 수집
- 다양한 등급/역할의 영웅 영입.
- 모든 영웅 5성까지 승급 가능 ([영웅 시스템 §7](영웅%20시스템.md#7-등급-시스템)).

#### 소환 유닛 매칭
- 슬롯에 어떤 소환 유닛을 묶을지 선택.
- 같은 소환 유닛을 여러 영웅이 공유 가능. 영웅에 따라 보정이 달라진다 ([영웅 시스템 §5](영웅%20시스템.md#5-영웅과-소환-유닛의-관계)).

#### 영웅별 소환 유닛 보정
- 슬롯의 영웅 특성에 따라 묶인 소환 유닛이 다르게 강화될 수 있다.
- 어떤 영웅 + 어떤 소환 유닛 조합이 어떤 공방전에 적합한지가 덱 빌딩의 핵심.

#### 링크 / 육성 / 장비
- 영웅 육성 (레벨, 승급, 스킬).
- 링크 시스템 적용 범위는 영웅 직접 출격 우선 (Phase 1 권장안, [영웅 시스템 §8](영웅%20시스템.md#8-링크-시스템과의-관계)).
- 장비 강화.

#### 중복 영웅 활용
- 같은 영웅 중복 획득 시 링크 확장 / 분해 / 코어 변환 등 활용 ([링크 시스템](영웅/링크%20시스템.md)).

#### 영입 / 수익화 정책 (보류)
- **제조 + 방문 영웅 + 가챠 병행 여부는 결정하지 않는다.** Phase 1은 영웅 수동 부여로 진행 ([Phase 1 구현 범위 §3.1](Phase%201%20구현%20범위.md#31-영입수익화-정책-보류)).

### 5.3 Phase 1 분량

| 항목 | 수량 |
|------|------|
| 영웅 | 5명 |
| 소환 유닛 | 5종 |
| 부대 카드 슬롯 | 5 |

### 5.4 역할

- **유입 동기**: 새 영웅/새 소환 유닛/새 조합이 직접적으로 덱 빌딩 옵션을 늘림.
- **장기 목표**: 단순 5성 달성이 아니라 다양한 부대 카드 운용 옵션 확보.
- **덱 빌딩의 깊이**: 영웅 5명을 뽑은 뒤에도, 그 영웅들에게 어떤 소환 유닛을 묶고 어떤 라인 분포로 출격시킬지가 남는다.
- **플레이 다양성**: 보유한 영웅/소환 유닛 조합에 따라 같은 스테이지도 다른 전술이 가능.

## 6. 3가지 컨텐츠 간 연결고리

### 6.1 흐름

```
[내실] 영지 시스템
  ↓ 자원 생산 (은화/식량/마석/보급/인력)
  ↓
소환 유닛 출격 자원 / 영웅 육성 / 장비 강화 / 수리
  ↓
[유입] 캐릭터와 부대 카드 수집
  ↓ 새 영웅 / 새 소환 유닛 / 새 조합
  ↓
[중심] 스테이지 공방전
  ↓ 적 본진 파괴 → 보상
  ↓
영지 강화 / 다음 영웅 육성 (반복)
```

### 6.2 연결 포인트

| From → To | 연결 |
|-----------|------|
| 영지 → 공방전 | 마나 강화, 본진 강화, 부속 시설 (시설 도입 여부는 결정 필요) |
| 영지 → 수집 | 영웅 육성/승급/장비 강화 자원 공급 |
| 수집 → 공방전 | 덱 빌딩 옵션 확장 (영웅 + 소환 유닛 + 보정 + 링크) |
| 공방전 → 영지 | 클리어 보상으로 영지 자원/건설 가속 |
| 공방전 → 수집 | 클리어 보상으로 육성 재료 / 모집권 등 (수익화 정책 결정 후 확정) |

## 7. 일일 / 장기 루프

### 7.1 일일 루프 (1일 단위)

```
로그인 →
영입/방문 영웅 확인 (정책 결정 후) →
영지 자원 수확 →
부대 카드 정비 (덱 / 영웅 / 소환 유닛 매칭) →
공방전 3~5회 →
수리 / 육성 →
로그아웃
```

### 7.2 장기 루프 (주/월 단위)

```
새 영웅 획득 →
소환 유닛 보정 / 덱 전략 옵션 확장 →
고난도 공방전 도전 →
클리어 보상 →
영지 / 육성 강화 (반복)
```

## 8. 개발 우선순위

| 우선순위 | 컨텐츠 | 이유 |
|---------|--------|------|
| 1순위 | **스테이지 공방전** | 실제 게임플레이가 일어나는 곳. 부대 카드 운용/라인 공방의 재미가 게임의 성패를 결정 |
| 2순위 | **캐릭터와 부대 카드 수집** | 덱 빌딩 옵션 / 장기 목표 / 매출 잠재력의 핵심 |
| 3순위 | **영지 시스템** | 내실과 선순환. 1~2순위 완성 후 보강 |

### 8.1 Phase별 포함 (Phase 1 기준 정렬)

| 컨텐츠 | Phase 1 | Phase 2 | Phase 3+ |
|--------|---------|---------|----------|
| 스테이지 공방전 | ✅ 필수 (1챕터 5스테이지, 지상 2 + 공중 1) | ✅ 확장 | ✅ 신규 맵 |
| 영웅 / 소환 유닛 | ✅ 필수 (영웅 5 / 소환 5) | ✅ 확장 (10~15 / 8~10) | ✅ 신규 |
| 적 / 보스 | ✅ 필수 (적 5 / 보스 1) | ✅ 확장 | ✅ 신규 |
| 영지 시스템 | ✅ 최소화 | ✅ 고도화 | ✅ 신 건물 |
| 영입 / 수익화 | ❌ 보류 (정책 미결정) | 정책 결정 후 도입 | 확장 |

> 더 상세한 Phase 1 포함/제외 범위는 [Phase 1 구현 범위](Phase%201%20구현%20범위.md)를 따른다.

## 9. 결정 필요

- 영웅 직접 출격 마나 비용 여부
- 영웅 전투불능 후 재출격 가능 여부
- 소환 유닛 매칭 방식 (영웅 고정 매칭 vs 병종 카테고리 슬롯 교체)
- 링크 시스템 적용 범위 (영웅 직접 출격에만 한정 vs 소환 유닛에도 적용)
- 제조 + 방문 영웅 + 가챠 병행 여부 (영입 / 수익화 정책)
- 방어 전용 모드의 컨텐츠 위치 (별도 모드 vs 이벤트 한정 vs 후순위 보류)
- 본진 자동 공격 / 부속 시설 도입 여부 (구 "성벽 무기" 처리)

| 실시간 타워디펜스 전투로 스테이지 클리어 | 공방형 라인 디펜스 전투로 적 본진 파괴 / 아군 본진 방어 (§4) |
| 마나로 유닛 배치 (배치 포인트) | 마나로 소환 유닛을 라인에 출격 (§4.2) |
| 영웅 무료 배치 (마나 0) | 영웅 직접 출격은 슬롯 비활성화 트레이드를 동반하는 결단 행동, 비용 결정 보류 (§4.2, §9) |
| 웨이브 시작 → 적 전멸 → 보상 | 적 출격 패턴 → 라인 공방 → 본진 파괴 / 방어 → 결과 (§4.3) |
| 캐릭터 수집 = 영웅 뽑기 | 영웅 수집 + 소환 유닛 매칭 + 부대 카드 운용 옵션 확장 (§5) |
| Phase 1 캐릭터 수집 20명 | Phase 1 영웅 5명 / 소환 유닛 5종 (§5.3, §8.1) |
| 방문 영웅 직구 등 영입/수익화 확정 서술 | 영입 / 수익화 정책 보류, Phase 1은 수동 부여 (§5.2, §9) |
| 성벽 내구도 0 = 패배 (확정) | 아군 본진 HP 0 = 패배 (§4.2) |
| 성벽 무기 (확정 기능) | 본진 자동 공격 / 부속 시설은 결정 필요 (§9) |
