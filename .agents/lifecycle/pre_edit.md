# Pre-Edit Checklist

1. List the exact target files.
2. Confirm each target is owned by the current Role.
3. For non-owned paths, stop unless the user has explicitly approved the edit.
4. Check whether each target is a shared resource.
5. Acquire a lock before editing any shared resource.
6. Check whether the target is sensitive.
7. Get user confirmation before editing sensitive files.
8. Re-read the original file immediately before making changes.
9. Preserve user changes and unrelated edits.
