# Task Complete Checklist

1. Run the planned validation or explain why it is not applicable.
2. Review changed files.
3. Summarize the result and any remaining risk.
4. Update `.agents/state/current_progress.md` if project progress changed.
5. Update only the relevant Role handoff file with next-session essentials.
6. Release any locks held by the session.
7. Update `.agents/state/session_registry.md` if the Role is no longer occupied.
8. Report changed files, validation, locks, and next steps to the user.
