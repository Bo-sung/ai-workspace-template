# During Work Checklist

1. Keep edits scoped to the assigned Role and task.
2. Re-check locks before touching shared resources.
3. Watch for unexpected file changes and treat them as user changes.
4. Update progress only when status meaningfully changes.
5. Keep handoff notes short and useful for the next session.
6. Do not create analysis or explanation documents unless requested.
7. If the task grows beyond the original request, stop and report.
