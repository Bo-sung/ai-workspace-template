# Pre-Commit Checklist

1. Run `git -C H:\Git\FantasyTowerDeffence_docs status`.
2. Run `git -C H:\Git\FantasyTowerDeffence_docs diff`.
3. Review untracked files.
4. Separate current-agent changes from pre-existing user changes.
5. Confirm no unrelated user changes are staged.
6. Check for sensitive files, generated files, binary replacements, and lock conflicts.
7. Run relevant validation.
8. Confirm the commit message follows `.agents/rules/commit_policy.md`.
