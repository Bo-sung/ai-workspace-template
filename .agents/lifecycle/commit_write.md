# Commit Write Checklist

1. Stage only the intended files.
2. Write a concise conventional commit message.
3. Do not include generated co-author lines, model signatures, or tool signatures.
4. Create the commit from the real Git root using `git -C H:\Git\FantasyTowerDeffence_docs`.
5. Capture the commit hash.
6. Run `git -C H:\Git\FantasyTowerDeffence_docs status`.
7. Report the hash and any remaining working tree changes.
