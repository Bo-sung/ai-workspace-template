# Context Restore Checklist

Use this after context compression, resume, handoff, or any uncertain memory state.

1. Ignore remembered status until it is confirmed from `.agents/state/`.
2. Re-read `.agents/state/session_registry.md`.
3. Re-read `.agents/state/resource_locks.md`.
4. Re-read `.agents/state/current_progress.md`.
5. Re-read `.agents/rules/module_permissions.md`.
6. Re-read the assigned Role handoff file.
7. Confirm whether your Role and task are still valid.
8. If state and local memory disagree, trust `.agents/state/` and report the mismatch.
